ISMT x Cloud Pulse Pvt Ltd.

Our journey from on-premises servers to the AWS Cloud

🖥

Before: On-Premises

All college services were hosted on local servers at Tinkune, Kathmandu. Limited scalability, single point of failure, manual backups, and high maintenance costs.

  • ❌ Server hardware aging & costly
  • ❌ No automatic failover
  • ❌ Slow website during admission peaks
  • ❌ Manual data backup process
→
☁

After: AWS Cloud

Migrated to a secure three-tier AWS VPC architected by Cloud Pulse Pvt Ltd. Auto-scaling, load balancing, and managed services ensure 99.9% availability worldwide.

  • ✅ Elastic auto-scaling EC2 fleet
  • ✅ Multi-AZ high availability
  • ✅ Application Load Balancer
  • ✅ Automated backups & monitoring

Why We Migrated to the Cloud

Scalability

Handles admission-season traffic spikes automatically with Auto Scaling Groups.

Cost Efficiency

Pay-as-you-go pricing replaced expensive server hardware refresh cycles.

Reliability

Multi-Availability Zone design keeps the college website online 24/7.

Security

Security Groups, NAT Gateways, and private subnets protect student data.

Disaster Recovery

Automated snapshots and cross-region backup strategies safeguard records.

Global Reach

Students abroad access results and resources with low latency via CloudFront.
